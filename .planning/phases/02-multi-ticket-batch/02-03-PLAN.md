**New callback — handleBatchCheck:**
```typescript
const handleBatchCheck = useCallback((tickets: string[]) => {
  const results = tickets.map(ticket => ({
    ticket,
    matches: matchPrizes(ticket, draw),
  }))
  setBatchTickets(tickets)
  setBatchResults(results)
}, [draw])
```

**Sorting logic for batch results (used when rendering BatchResultList):**
```typescript
const sortedBatchResults = [...batchResults].sort((a, b) => {
  const aWon = a.matches.length > 0 ? 0 : 1
  const bWon = b.matches.length > 0 ? 0 : 1
  return aWon - bWon
})
```

**Derived values for BatchResultSummary:**
```typescript
const wonBatchTickets = sortedBatchResults.filter(r => r.matches.length > 0)
const lostBatchCount = batchResults.length - wonBatchTickets.length
```
