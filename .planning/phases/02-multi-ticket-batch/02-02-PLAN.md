Create `src/components/BatchResultSummary.tsx` — a `'use client'` component (needs animation classes).

Props interface:
```typescript
interface BatchResultSummaryProps {
  totalTickets: number    // total unique tickets checked
  wonTickets: { ticket: string; matches: PrizeMatch[] }[]  // only won tickets
  lostCount: number       // number of tickets with 0 matches
}
```

Import: `PrizeMatch`, `PRIZE_NAMES`, `PrIZE_AMOUNTS` from `@/lib/types`.

Visual contract (per UI-SPEC "BatchResultSummary" section):

Outer container:
- `rounded-xl bg-white border border-border shadow-card p-md`
- `animate-[fade-in-up_0.3s_ease-out]` on mount
- `role="region"` with `aria-label="สรุปผลรวม"`

Content structure (top to bottom):

1. **Heading**: "สรุปผลรวม" — `text-xl font-semibold text-text` (20px semibold)

2. **Ticket counts row**: `flex flex-row gap-sm` (flex-wrap for narrow screens)
   - "ทั้งหมด {N} ใบ" — `text-text text-base` (16px)
   - "ถูก {W} ใบ" — `text-win text-base font-semibold` (green, bold)
   - "ไม่ถูก {L} ใบ" — `text-text-muted text-base` (muted gray)

3. **Total prize amount** (only if `wonTickets.length > 0`):
   - "รางวัลรวม {amount}" — `text-[28px] font-semibold text-gold`
   - Amount formatted: `totalAmount.toLocaleString('th-TH') + ' บาท'`
   - Compute totalAmount: `wonTickets.reduce((sum, t) => sum + t.matches.reduce((s, m) => s + m.amount, 0), 0)`
   - Note: a ticket can win multiple prizes, so sum ALL matches for each won ticket

4. **Big win callout** (only if ANY ticket won first or adjacent prize):
   - `bg-gold/10 rounded-lg px-md py-sm border border-gold/30`
   - Text: "ถูกรางวัลใหญ่!" — `text-base font-semibold text-gold`
   - Check: `wonTickets.some(t => t.matches.some(m => m.id === 'first' || m.id === 'adjacent'))`

5. **Per-tier breakdown** (only if `wonTickets.length > 0`):
   - `flex flex-wrap gap-xs` row
   - Aggregate all matches across all won tickets into per-tier counts
   - Each item: `"{prize_name} x {count}"` — `text-sm text-text-muted` (14px)
   - Example output: "รางวัลที่ 1 x 1", "รางวัลที่ 3 x 2", "เลขท้าย 2 ตัว x 5"
   - Use `PRIZE_NAMES[match.id]` for display name

6. **All lost state** (when `wonTickets.length === 0`):
   - After counts row, show: "ไม่ถูกรางวัลใดเลย" — `text-base text-text-muted` (16px muted)
   - No prize amount, no breakdown, no big win callout
