  <behavior>
    - parseBatchInput("") returns { tickets: [], duplicateCount: 0, invalidCount: 0 }
    - parseBatchInput("123456") returns { tickets: ["123456"], duplicateCount: 0, invalidCount: 0 }
    - parseBatchInput("123456\n789012") returns { tickets: ["123456", "789012"], duplicateCount: 0, invalidCount: 0 }
    - parseBatchInput("123456, 789012, 345678") returns { tickets: ["123456", "789012", "345678"], duplicateCount: 0, invalidCount: 0 }
    - parseBatchInput("123456 789012 345678") returns { tickets: ["123456", "789012", "345678"], duplicateCount: 0, invalidCount: 0 }
    - parseBatchInput("123456\n\n789012") returns { tickets: ["123456", "789012"], duplicateCount: 0, invalidCount: 0 }
    - parseBatchInput("123456\n123456") returns { tickets: ["123456"], duplicateCount: 1, invalidCount: 0 }
    - parseBatchInput("12345") returns { tickets: [], duplicateCount: 0, invalidCount: 1 }
    - parseBatchInput("1234a6") returns { tickets: [], duplicateCount: 0, invalidCount: 0 } (regex only matches digits)
    - parseBatchInput("12345 789012") returns { tickets: ["789012"], duplicateCount: 0, invalidCount: 1 }
    - parseBatchInput with 51 unique valid numbers returns tickets capped at 50 (first 50 kept)
    - parseBatchInput("1234567") returns { tickets: [], duplicateCount: 0, invalidCount: 0 } (7-digit number does not match /\d{6}/g exactly — but actually /\d{6}/g WILL match 6 digits inside 7 digits, so this should return { tickets: ["123456"], duplicateCount: 0, invalidCount: 0 })
    - parseBatchInput("1234567") — re-reading regex /\d{6}/g behavior: it finds non-overlapping 6-digit sequences. "1234567" produces ["123456"]. This is correct behavior per UI-SPEC: "extract all matches of /\d{6}/g"
  </behavior>

  <action>
Create `src/lib/batch-parse.ts` with:

1. Export interface `BatchParseResult`:
```typescript
export interface BatchParseResult {
  tickets: string[]   // unique valid 6-digit ticket numbers, max 50
  duplicateCount: number  // how many were deduplicated
  invalidCount: number    // count of non-6-digit numeric-only sequences found
}
```

2. Export function `parseBatchInput(input: string): BatchParseResult`:
   - Use regex `/\d{6}/g` to extract all 6-digit sequences from the input string
   - Count duplicates: total matches minus unique set size
   - Count "invalid" sequences: use `/\b\d+\b/g` to find all standalone number tokens, subtract the count of exactly-6-digit tokens — these are numbers that are not 6 digits long. If this is complex, alternative: count tokens matching `/\b\d{1,5}\b|\b\d{7,}\b/g` (numbers that are NOT exactly 6 digits).
   - Deduplicate: `[...new Set(matches)]` preserving first-occurrence order
   - Cap at 50: `.slice(0, 50)`
   - Return `{ tickets, duplicateCount, invalidCount }`

3. Export constant `MAX_BATCH_SIZE = 50`

Per UI-SPEC "Batch Input Parsing" section: no debounce needed (regex on <1KB textarea is instantaneous), separator-agnostic (regex handles all), deduplicate on paste.
  </action>
